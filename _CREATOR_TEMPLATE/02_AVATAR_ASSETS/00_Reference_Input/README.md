# 00_Reference_Input

Carpeta para imágenes y videos de referencia de avatar (Ruta B del onboarding).

Coloca aquí fotos o clips del creator de referencia antes de que el agente extraiga la ficha de personaje.

**Formatos aceptados:** `.jpg`, `.jpeg`, `.png`, `.mp4`, `.mov`

El agente leerá estos archivos para extraer: apariencia física, energía, estilo de comunicación y gancho de atención — y construirá la ficha del avatar a partir de ellos.
